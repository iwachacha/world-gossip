# WorldGossip プロジェクトコンセプト

作成日: 2026-04-14 JST  
ステータス: Final  
役割: この文書は WorldGossip の企画思想と運営原則を定義する。技術選定は `worldgossip-optimal-design.md`、実装仕様は `worldgossip-technical-design.md` を正本とする。

## 1. 一文で言うと

WorldGossip は、各国の人たちが互いの国や文化について語っている投稿を編集的につなぎ直し、X のリプライ欄で自然な国際交流、比較、軽い議論が起きるきっかけを作るプロジェクトである。

## 2. アカウント定義

### 名前

**WorldGossip**

### 自己紹介文

**Found you talking about each other. The rest is yours.**

## 3. 何を作るのか

このプロジェクトが作るのは、単なる海外反応紹介アカウントでも、単なるバズ投稿の再掲アカウントでもない。  
目指すのは、`世界の反応差を編集し、会話が起きやすい形で提示するメディア兼会話導線` である。

WorldGossip は、次の 3 つを同時に満たす必要がある。

- 別の国ではどう見えているのかが分かる
- 自分の国の視点で参加したくなる
- 会話は起きるが、危険な対立へは行きすぎない

## 4. コア仮説

X では自動翻訳と越境閲覧が進み、以前より他言語圏の投稿が見えやすくなっている。  
その結果、次のようなやりとりが可視化されやすくなっている。

- 他国文化への好意や驚き
- ちょっとした誤解や温度差
- 比較による共感や軽い banter
- 素朴な open question
- 国ごとの感覚差が生む自然な議論

WorldGossip は、この流れをそのまま眺めるのではなく、`会話が起きる組み合わせ` と `入っていきやすい問い` を編集することで価値を作る。

## 5. 体験設計

### 5.1 ユーザーに起きてほしいこと

- 「向こうではそう見えるのか」と比較したくなる
- 「自分の国ではこうだ」と書き込みたくなる
- 別の国の人の反応を見て、追加で会話したくなる
- 軽いバチバチや温度差も、危険ではなく面白い会話として楽しめる

### 5.2 避けたいこと

- ただ炎上ネタを並べるだけになる
- 文脈を失った切り抜きになる
- 対立煽りや差別の増幅に見える
- 投稿者や国民性を単純化しすぎる

## 6. WorldGossip の役割

WorldGossip は、世界の人々を無理に仲良くさせる装置でも、喧嘩の場を作る装置でもない。  
役割は `編集者兼きっかけ提供者` である。

やるべきことは次である。

- 会話のきっかけになる素材を見つける
- 反応差、共感、温度差を分かりやすく見せる
- 自分の国の視点で返したくなる問いを置く
- 軽い熱量は残しつつ、危険な方向には押し出さない

主役は運営者ではなく、投稿と、それに反応する各国の人たちの会話である。

## 7. 扱うテーマ

初期に扱うのは、国際的に比較しやすく、かつ危険度をコントロールしやすいテーマに限定する。

- 食文化
- 菓子、飲食、調味料、BBQ などの生活圏比較
- 旅行、観光、街の印象
- 生活習慣、マナー、便利グッズ
- 美意識や好みの差
- ネットミームや流行
- 他国への素朴な憧れ、誤解、驚き
- 国ごとのテンション差
- 軽い banter と open question

## 8. 触れない領域

次は意図的に扱わない。

- 戦争
- 政治
- 宗教
- 深刻な差別やヘイト
- 排外主義
- 現実の被害を伴う事件
- 文脈が欠けると危険なセンシティブ話題
- 個人攻撃が主目的の投稿

許容するのは `軽い banter` や `文化比較の温度差` までであり、`本気の敵意` や `差別の増幅` は対象外とする。

## 9. 投稿の考え方

投稿は「紹介」ではなく、`問いかけ付きの編集` として作る。

投稿ごとに必要な要素は次の通り。

- 見るだけで構図が分かる
- 何が共通し、何がズレているかが一目で伝わる
- 自分の国の立場で返信したくなる
- ケンカ腰ではなく会話に入りやすい
- 軽い熱量はあるが、危険な方向には行きすぎない

## 10. 運営原則

### 10.1 人間レビュー前提

完全自動投稿にはしない。  
最終公開前に必ず人間が `文脈` `温度感` `対立リスク` を確認する。

### 10.2 収集量より編集品質

この企画の価値は大量収集ではなく、`どの投稿を、どの組み合わせで、どの角度で見せるか` にある。

### 10.3 会話の起点を作る

投稿の価値は本文単体ではなく、`リプライ欄で何が始まるか` まで含めて評価する。

### 10.4 国際交流とエンタメの両立

WorldGossip は堅い国際理解メディアでも、雑な炎上メディアでもない。  
`比較の面白さ` と `会話の安全性` の両立を目指す。

## 11. 成功条件

WorldGossip の成功は、単なるインプレッションではなく、次の状態で判断する。

- 各国のユーザーが自分の視点を書き込みたくなる
- リプライ欄に複数言語の自然な会話が生まれる
- 共感、比較、軽い議論が継続的に起きる
- 荒れすぎず、でも無味無臭でもない温度帯を保てる
- 投稿ごとに「会話が起きる型」が学習されていく

## 12. 非目標

次は WorldGossip の初期目標ではない。

- 全世界全言語を最初からカバーすること
- 収集から公開までを完全自動化すること
- 事実検証メディアやニュース解説メディアになること
- 政治、歴史、思想対立を扱うこと
- 勝ち負けを決める国際バトルアカウントになること

## 13. 最終コンセプト

WorldGossip は、世界の人たちが互いについて語っている投稿を見つけ、  
それを `会話が始まりやすい構図` と `入りたくなる問い` に編集して提示するプロジェクトである。

少しだけおせっかいに、でも煽りすぎず、  
各国の人たちが `ちょっと話したくなる国際的な交差点` を X 上に作る。
