# WorldGossip プロジェクトコンセプト

作成日: 2026-04-14 JST  
ステータス: Revised for flexible conversation-trigger collection (2026-04-15)
役割: この文書は WorldGossip の企画思想と運営原則を定義する。技術選定は `worldgossip-optimal-design.md`、実装仕様は `worldgossip-technical-design.md` を正本とする。

## 1. 一文で言うと

WorldGossip は、各国の人たちが互いの国や文化、言葉、しょうもない違いについて語っている投稿を拾い、単体でも編集的な並置でも、X のリプライ欄で自然な国際交流、比較、軽い議論が起きるきっかけを作るプロジェクトである。

## 2. アカウント定義

### 名前

**WorldGossip**

### 自己紹介文

**Found you talking about each other. The rest is yours.**

## 3. 何を作るのか

このプロジェクトが作るのは、単なる海外反応紹介アカウントでも、単なるバズ投稿の再掲アカウントでもない。  
目指すのは、`世界の反応差や会話の火種を編集し、会話が起きやすい形で提示するメディア兼会話導線` である。

WorldGossip は、次の 3 つを同時に満たす必要がある。

- 別の国ではどう見えているのかが分かる
- 自分の国の視点で参加したくなる
- 会話は起きるが、危険な対立へは行きすぎない

## 4. コア仮説

X では自動翻訳と越境閲覧が進み、以前より他言語圏の投稿が見えやすくなっている。  
その結果、次のようなやりとりが可視化されやすくなっている。

- 他国文化への好意や驚き
- ちょっとした誤解や温度差
- 比較による共感や軽い banter
- 素朴な open question
- 国ごとの感覚差が生む自然な議論

WorldGossip は、この流れをそのまま眺めるのではなく、`会話が起きる素材` と `入っていきやすい問い` を編集することで価値を作る。

ここでいう素材は 2 種類ある。

- 単体で完結しており、1 つの投稿の中にすでに多国籍会話の火種があるもの
- 2 つ以上の投稿を並べることで温度差や共通点が立ち上がるもの

WorldGossip は後者だけに依存しない。
むしろ理想は、`その投稿ひとつで各国の人がつい参加したくなる` 場も継続的に見つけることである。

## 5. 体験設計

### 5.1 ユーザーに起きてほしいこと

- 「向こうではそう見えるのか」と比較したくなる
- 「自分の国ではこうだ」と書き込みたくなる
- 別の国の人の反応を見て、追加で会話したくなる
- 軽いバチバチや温度差も、危険ではなく面白い会話として楽しめる

### 5.2 避けたいこと

- ただ炎上ネタを並べるだけになる
- 文脈を失った切り抜きになる
- 対立煽りや差別の増幅に見える
- 投稿者や国民性を単純化しすぎる

## 6. WorldGossip の役割

WorldGossip は、世界の人々を無理に仲良くさせる装置でも、喧嘩の場を作る装置でもない。  
役割は `編集者兼きっかけ提供者` である。

やるべきことは次である。

- 会話のきっかけになる素材を見つける
- 反応差、共感、温度差を分かりやすく見せる
- 自分の国の視点で返したくなる問いを置く
- 軽い熱量は残しつつ、危険な方向には押し出さない

主役は運営者ではなく、投稿と、それに反応する各国の人たちの会話である。

## 7. 扱う会話トリガー

初期は危険度をコントロールしやすい領域を優先するが、扱う価値を `固定テーマの一覧` で縛りすぎない。
見るべきなのはテーマそのものより、`各国の人が入りやすい会話トリガーになっているか` である。

WorldGossip が重視するのは、たとえば次のような火種である。

- 食、値段、暮らし、街、サービスの違い
- 旅行や生活実感のミクロ発見
- スラング、言い回し、呼び方、翻訳ズレ、言葉遊び
- ちょっとくだらない比較、低 stakes な論争、少しお下品な日常語
- 共通ブランド、ローカライズ、パッケージ差
- 習慣、マナー、ルール感覚の違い
- 各国の人が「うちではこう」と書き込みやすい roll call 型の問い
- 他国への素朴な憧れ、誤解、驚き
- 国ごとのテンション差や、軽い banter

逆に、`初期は食が強かったから今後も食を中心にする` のような固定化は避ける。
大事なのは、コンセプトに合う会話が実際に起きるなら、題材は広く柔軟に受け止めることである。

## 8. 触れない領域

次は意図的に扱わない。

- 戦争
- 政治
- 宗教
- 深刻な差別やヘイト
- 排外主義
- 現実の被害を伴う事件
- 文脈が欠けると危険なセンシティブ話題
- 個人攻撃が主目的の投稿

許容するのは `軽い banter` や `文化比較の温度差` までであり、`本気の敵意` や `差別の増幅` は対象外とする。

## 9. 投稿の考え方

投稿は「紹介」ではなく、`問いかけ付きの編集` として作る。

編集単位は 2 種類ある。

- `single-post`
  - 1 つの投稿だけで多国籍会話の起点になっているもの
- `editorial juxtaposition`
  - 複数投稿を並べることで構図が立ち上がるもの

どちらが主役かは固定しない。
その時点でいちばん自然に会話が起きる単位を選ぶ。

投稿ごとに必要な要素は次の通り。

- 見るだけで構図が分かる
- 何が共通し、何がズレているかが一目で伝わる
- 自分の国の立場で返信したくなる
- ケンカ腰ではなく会話に入りやすい
- 軽い熱量はあるが、危険な方向には行きすぎない

## 10. 運営原則

### 10.1 人間レビュー前提

完全自動投稿にはしない。  
最終公開前に必ず人間が `文脈` `温度感` `対立リスク` を確認する。

### 10.2 収集量より編集品質

この企画の価値は大量収集ではなく、`どの投稿を、どの単位で、どの角度で見せるか` にある。

### 10.3 会話の起点を作る

投稿の価値は本文のテーマ名ではなく、`リプライ欄で何が始まるか` まで含めて評価する。

そのため、次のような素材も積極的に扱う。

- 単体で各国 reply が立っている投稿
- 「うちではこう言う」「それ英語だとこう」型の言葉遊び
- しょうもないが多国籍で笑える低 stakes な議論

### 10.4 国際交流とエンタメの両立

WorldGossip は堅い国際理解メディアでも、雑な炎上メディアでもない。  
`比較の面白さ` と `会話の安全性` の両立を目指す。

## 11. 成功条件

WorldGossip の成功は、単なるインプレッションではなく、次の状態で判断する。

- 各国のユーザーが自分の視点を書き込みたくなる
- リプライ欄に複数言語の自然な会話が生まれる
- 共感、比較、軽い議論が継続的に起きる
- 荒れすぎず、でも無味無臭でもない温度帯を保てる
- 投稿ごとに「会話が起きる型」が学習されていく
- 単体完結の投稿と編集的な並置の両方で、自然な参加が起きる

## 12. 非目標

次は WorldGossip の初期目標ではない。

- 全世界全言語を最初からカバーすること
- 収集から公開までを完全自動化すること
- 事実検証メディアやニュース解説メディアになること
- 政治、歴史、思想対立を扱うこと
- 勝ち負けを決める国際バトルアカウントになること

## 13. 最終コンセプト

WorldGossip は、世界の人たちが互いについて語っている投稿を見つけ、  
それを `会話が始まりやすい構図` と `入りたくなる問い` に編集して提示するプロジェクトである。

少しだけおせっかいに、でも煽りすぎず、  
各国の人たちが `ちょっと話したくなる国際的な交差点` を X 上に作る。

その交差点は、立派な文化比較だけでなく、
スラング、ダジャレ、言い回し、しょうもない違いの笑いから始まってもよい。
